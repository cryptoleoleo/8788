BAW 按需启动完整包 · Mac 1.0.0-rc4 / 扩展 1.4.0

首次安装
1. macOS 13.5+；先安装 Node.js 24 和 Binance Agentic Wallet CLI 1.11.0。
   CLI 安装命令：npm install -g @binance/agentic-wallet@1.11.0
2. 解压，运行“安装 BAW 多钱包增强版.app”。安装在 ~/Applications/BAW-Original-Multi。
   安装器在当前用户 Chrome NativeMessagingHosts 目录注册启动组件，无需管理员权限。
   安装器未做 Apple 公证；按系统正常提示允许运行，不要关闭系统安全设置。
   如果旧服务正在运行，先在原终端按 Control+C，安装器不会杀进程。
3. Chrome 打开 chrome://extensions，启用开发者模式，加载已解压的扩展程序。
   选择 ~/Applications/BAW-Original-Multi/chrome-extension（直接包含 manifest.json）。
   停用旧扩展；新版固定扩展 ID，升级时始终使用安装目录里的这一份。
4. 允许 GMGN / Debot 网站访问权限。以后直接打开插件，后台自动启动 BAW，无需终端。
   若 Node 升级后路径变化，重新运行安装器注册组件。

服务默认 8787；不改钱包、交易参数或身份数据。关闭侧栏不会继续面板跟单；
服务可能仍在后台运行，再次打开插件复用。组件不是开机自启动，不会自动配对或交易。
本包包含协作者已提交扩展，并非对最初截图原扩展来源的确认。
保留手动启动命令用于排查；日常无需使用。

多钱包
进入“钱包”页，点击“添加身份”，填写名称并选择分组。
每个身份点击“连接”，打开 CLI 返回的 Binance 登录页，由对应身份在 Binance App 完成配对。
完成后点击“等待配对完成”；使用“检查”读取 BSC 地址与会话状态。
不同身份必须对应不同 BSC 地址；不允许给同一个地址创建重复执行钱包。
可新建/重命名分组、移动钱包、设为当前钱包。
“交易”页启用分组买卖，勾选分组或单个钱包。原来的买入档位表示每钱包金额。
确认框列出钱包、各自金额和总计（不含 Gas），之后逐个调用原版交易流程。
分组卖出按各钱包自己的持仓比例执行。某钱包失败后继续其余钱包，不自动重试失败钱包。
未启用分组时，保留原版单钱包行为。原来的快速模式、按钮金额、滑点等默认值未改。
原页面底部的预设监听仍使用原有身份，多钱包跟买在新增“跟单”页配置。

跟单
填写一个或多个目标 BSC 地址，选择 Gang / Flap / Four.meme 信号及执行钱包。
固定金额适用于上述信号。金额镜像及最低买入金额过滤仅处理已确认以 BNB 计价的
Gang Soft 事件；无法确认计价币的其他事件会跳过，避免把其他币种数量当作 BNB。
设定冷却时间、滑点；新增任务默认预演。保存不会启动，启动真实跟单需要界面确认。
仅跟买入，复用原版代币解析与交易路径；原程序不支持的路线会报错，不另建交易引擎。
面板必须保持打开。关闭、离线或服务重启后不自动恢复，不补买历史信号。
停止会阻止后续签名请求，但已经广播的交易不能撤销，结果以原日志和链上为准。
默认公共 WSS：wss://bsc-rpc.publicnode.com；可通过 BAW_COPY_WSS 指定 wss:// 节点。
系统代理沿用现有 Mac 启动适配；实际网络/WSS 连通性需要在朋友的环境中检查。

数据与身份隔离
程序本身不导入私钥或助记词。新增身份仍由 Binance Agentic Wallet CLI 配对、签名。
每个新身份使用独立 BINANCE_BAW_DIR；CLI 的钥匙串服务名也单独隔离。
原有身份继续使用原有 CLI 配置与钥匙串位置，不复制登录数据。
独立身份数据位于 ~/Library/Application Support/BAW-Original-Multi/identities/。
不要把这个目录、钥匙串或自己的登录文件打包给朋友。朋友必须自己逐一配对。
本 ZIP 只含静态程序、安装器、源代码与虚拟钱包测试材料，不含任何个人钱包登录数据。

Debot CA 兼容（rc2）
可直接在 CA 输入框粘贴 https://debot.ai/token/bsc/312069_0x... 形式的链接。
自动提取完整 0x 地址，支持链接查询参数、片段以及“粘贴解析”按钮。
地址栏 ?ca= 参数也接受经过 URL 编码的 Debot BSC 链接。
非 BSC 的 Debot 链接不会作为 BSC 代币解析；不访问 Debot 页面，不改变交易流程。
