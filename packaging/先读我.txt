BAW 原程序多钱包增强版 · Mac 1.0.0-rc1（集成验收版）

这是在朋友提供的原版 BAW 页面和 Node 服务中增加多钱包与跟单的版本。
没有新建 Chrome 扩展外壳，没有 iframe 替代插件，也没有更改 8788 品牌。
原 Chrome 扩展文件仍未提供：本 ZIP 没有 manifest.json，没有可直接导入 Chrome 的目录。
因此它是完整的增强版程序与 Mac 安装包，不是完整原版侧边栏插件分发包。

安装与启动
1. 本包面向 macOS 13.5 或更新系统（Apple 芯片 / Intel）。
   安装 Node.js 24 LTS：https://nodejs.org/
   Node 24 的系统要求见：https://github.com/nodejs/node/blob/v24.13.0/BUILDING.md#platform-list
   多身份适配目前锁定 Binance CLI 1.11.0；在终端运行：
   npm install -g @binance/agentic-wallet@1.11.0
   若已有其他版本，请先确认是否要切换；安装器不会替你升级或降级全局 CLI。
2. 解压 ZIP，双击“安装 BAW 多钱包增强版.app”。
   安装到 ~/Applications/BAW-Original-Multi，不覆盖 BAW-Original-Mac 或之前的错误插件目录。
   安装器使用本地临时签名，未做 Apple 公证。若系统阻止打开，可按 macOS 的提示在
   “系统设置 → 隐私与安全性”中确认此本地安装器。不要关闭系统安全设置。
3. 点击安装器中的“启动原版服务”，或双击安装目录中的“启动原版服务.command”。
   保留终端窗口；Control+C 只停止此启动窗口中的服务。
   默认地址沿用原代码：http://127.0.0.1:8787。
   端口占用会退出；请先辨认原进程，在原启动窗口停止它，不会自动杀进程或切换到 8788。
4. 已有真正原扩展的用户继续使用原来的侧边栏入口，并核对原扩展配置地址。
   暂无原扩展时，可用终端打印的地址验收原程序页面；这不等于原侧边栏加载通过。
   只有确认原扩展确实使用其他端口时，才在 mac-options.json 中把 port:null 改为对应数字。

多钱包
进入“钱包”页，点击“添加身份”，填写名称并选择分组。
每个身份点击“连接”，打开 CLI 返回的 Binance 登录页，由对应身份在 Binance App 完成配对。
完成后点击“等待配对完成”；使用“检查”读取 BSC 地址与会话状态。
不同身份必须对应不同 BSC 地址；不允许给同一个地址创建重复执行钱包。
可新建/重命名分组、移动钱包、设为当前钱包。
“交易”页启用分组买卖，勾选分组或单个钱包。原来的买入档位表示每钱包金额。
确认框列出钱包、各自金额和总计（不含 Gas），之后逐个调用原版交易流程。
分组卖出按各钱包自己的持仓比例执行。某钱包失败后继续其余钱包，不自动重试失败钱包。
未启用分组时，保留原版单钱包行为。原来的快速模式、按钮金额、滑点等默认值未改。
原页面底部的预设监听仍使用原有身份，多钱包跟买在新增“跟单”页配置。

跟单
填写一个或多个目标 BSC 地址，选择 Gang / Flap / Four.meme 信号及执行钱包。
固定金额适用于上述信号。金额镜像及最低买入金额过滤仅处理已确认以 BNB 计价的
Gang Soft 事件；无法确认计价币的其他事件会跳过，避免把其他币种数量当作 BNB。
设定冷却时间、滑点；新增任务默认预演。保存不会启动，启动真实跟单需要界面确认。
仅跟买入，复用原版代币解析与交易路径；原程序不支持的路线会报错，不另建交易引擎。
面板必须保持打开。关闭、离线或服务重启后不自动恢复，不补买历史信号。
停止会阻止后续签名请求，但已经广播的交易不能撤销，结果以原日志和链上为准。
默认公共 WSS：wss://bsc-rpc.publicnode.com；可通过 BAW_COPY_WSS 指定 wss:// 节点。
系统代理沿用现有 Mac 启动适配；实际网络/WSS 连通性需要在朋友的环境中检查。

数据与身份隔离
程序本身不导入私钥或助记词。新增身份仍由 Binance Agentic Wallet CLI 配对、签名。
每个新身份使用独立 BINANCE_BAW_DIR；CLI 的钥匙串服务名也单独隔离。
原有身份继续使用原有 CLI 配置与钥匙串位置，不复制登录数据。
独立身份数据位于 ~/Library/Application Support/BAW-Original-Multi/identities/。
不要把这个目录、钥匙串或自己的登录文件打包给朋友。朋友必须自己逐一配对。
本 ZIP 只含静态程序、安装器、源代码与虚拟钱包测试材料，不含任何个人钱包登录数据。

原页面 connect/resolve/uniBuy/dexBuy 回调集成测试，以及 Mac 安装器文件复制验证。
所有交易/链上响应测试都使用测试桩；没有执行真实买卖、授权、转账或自动跟单。
尚未验证：两个真实 Binance 身份分别完成配对、真实钱包交易、真实链上跟单、
原 Chrome 扩展加载。后者需要朋友提供真正的原扩展文件。

向朋友索取原扩展
请朋友在安装截图中插件的那台电脑上，手动打开 Chrome 扩展管理页，找到
“8788 Trading Panel”。如果是“加载已解压的扩展程序”，索取当时选择的独立目录，
目录应直接包含 manifest.json 以及所引用的脚本、侧栏页面、图标等文件。
如果从商店安装，请提供商店链接或扩展 ID，由发布方提供原扩展的干净源码/分发包。
无需发送浏览器用户资料、Cookie、Local Storage、会话或钱包目录。
收到原扩展后再核对它的地址配置、刷新/新窗口/设置行为及 Mac 实际加载结果。
